## 🚀 Running the Portfolio Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/kunal0395/portfolio.git
   cd portfolio
   ```

2. **Run locally:**
   Simply open `index.html` in your favorite browser, or start a local server:
   ```bash
   # Using Python
   python -m http.server 3000

   # Or using Node.js / npx
   npx serve .
   ```

3. **Visit:** `http://localhost:3000`
